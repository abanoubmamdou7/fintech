# FinTech Motion — interactive prototype

Open `index.html` in a modern browser. No build step or backend required.

Features: 3-column interactive course UI, 14 lessons across seven modules, animated SVG transaction paths and nodes, next/back/replay/pause, amount input, lesson navigation, completed lessons saved locally, and a responsive layout. All scenarios are educational mockups and do not process real money.

The layout is inspired by the user-provided screenshot; artwork and code are original.
